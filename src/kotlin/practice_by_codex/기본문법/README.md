# Codex Kotlin 기본 문법 문제 기획서

서로 단절된 예제 대신 **우주 탐사대 운영 프로그램**을 조금씩 완성하며 Kotlin 문법을 익히는 문제 목록입니다.
각 함수는 예시 입출력을 만족하도록 작성하고, 보너스 조건은 기본 문제를 푼 뒤 도전합니다.

## 난이도 구성

| 단계 | 문제 | 목표 | 완료 기준 |
|---|---:|---|---|
| A · 기본 | C01~C09 | 값, 함수, 조건, 범위, 반복을 사용해 작은 로직 구현 | 각 함수의 입력·출력 타입과 제어 흐름을 설명할 수 있음 |
| B · 중급 | C10~C18 | null과 컬렉션을 안전하고 선언적으로 처리 | `!!` 없이 빈 값 정책을 세우고 컬렉션 체인을 읽을 수 있음 |
| C · 고급 | C19~C24 | 클래스로 상태와 도메인의 경우의 수를 모델링 | 불변성, 캡슐화, 다형성, 완전한 `when`을 선택할 수 있음 |
| D · 최고급 | C25~C30 | 함수를 값으로 다루고 여러 변환을 조합 | 고차 함수와 스코프 함수를 남용하지 않고 실전 파이프라인 구현 |

난이도는 코드 길이가 아니라 **타입 설계와 언어 기능을 선택하는 판단의 복잡도**를 기준으로 나눴습니다.

## 진행 규칙

1. 문제 번호 순서대로 풉니다.
2. 먼저 표준 라이브러리 문서를 찾지 않고 10분간 직접 시도합니다.
3. 막히면 Codex에게 `C01 힌트만 줘`라고 요청합니다.
4. 풀이 뒤에는 `C01 채점해줘. 정답 코드는 바로 보여주지 마`라고 요청합니다.
5. 모든 예시뿐 아니라 빈 컬렉션, 경계값, `null`도 직접 테스트합니다.

## Kotlin을 주 언어로 만들기 위한 기준

문제를 통과하는 것만으로 끝내지 말고 아래 기준으로 자신의 코드를 다시 살펴봅니다.

- 기본 선택은 `var`보다 `val`, 변경 가능한 컬렉션보다 읽기 전용 컬렉션입니다.
- 값을 결정하는 로직은 가능한 경우 문장형 코드보다 `if`, `when`, 함수 표현식 본문을 활용합니다.
- `null`은 `!!`로 피하지 말고 타입과 흐름 안에서 `?.`, `?:`, `let`, `takeIf`로 처리합니다.
- 컬렉션 코드는 “어떻게 반복할지”보다 `filter`, `map`, `groupBy`처럼 “무엇을 원하는지”가 읽히게 작성합니다.
- 데이터는 가능한 한 불변 `data class`로 모델링하고, 변경은 `copy`로 표현합니다.
- `when`에서 다뤄야 할 경우의 수가 정해져 있다면 `enum` 또는 `sealed class`로 컴파일러의 도움을 받습니다.
- 스코프 함수는 짧고 목적이 분명할 때만 사용합니다. `apply`는 객체 설정, `let`은 nullable 값 변환이라는 식으로 역할을 구분합니다.
- 함수는 한 가지 책임만 갖게 하고, 함수 이름과 반환 타입만 보고도 동작을 예측할 수 있게 만듭니다.

## 권장 반복 학습법

각 문제는 한 번 풀고 끝내지 않고 다음 순서로 반복합니다.

1. **첫 풀이:** 가장 익숙한 방식으로 `check(...)`를 통과시킵니다.
2. **Kotlin식 리팩터링:** 불필요한 `var`, 강제 언래핑 `!!`, 수동 반복을 줄입니다.
3. **설명:** 함수의 입력 타입, 출력 타입, 빈 값 정책을 소리 내어 설명합니다.
4. **변형:** 테스트 값을 하나 추가하고 요구사항을 조금 바꿔 다시 풉니다.
5. **복습:** 다음 날 파일을 초기 상태로 되돌려 힌트 없이 다시 작성합니다.

주 언어 수준의 기준은 문법을 암기하는 것이 아니라, 요구사항을 보았을 때 적절한 타입과 표준 라이브러리 함수가 자연스럽게 떠오르는 것입니다.

## 1단계 — 값과 함수

### C01. 산소 잔량

- 문법: `val`, `var`, 타입 추론, 산술 연산
- 현재 산소량과 사용량을 받아 남은 양을 반환하는 `remainingOxygen`을 작성합니다.
- 산소량은 음수가 될 수 없으며, 부족하면 `0`을 반환합니다.
- 예시: `remainingOxygen(100, 35) == 65`, `remainingOxygen(20, 30) == 0`

### C02. 탐사대 호출 부호

- 문법: 문자열 템플릿, 함수 파라미터, 표현식 본문
- 이름과 기수 번호를 받아 `"이름-번호"` 형식으로 반환합니다.
- 예시: `callSign("NOVA", 7) == "NOVA-7"`

### C03. 거리 단위 변환

- 문법: `Int`, `Double`, 명시적 타입 변환
- 미터 값을 킬로미터 값으로 변환합니다.
- 정수 나눗셈으로 소수 부분이 사라지지 않도록 주의합니다.
- 예시: `toKilometers(1_500) == 1.5`

## 2단계 — 조건과 범위

### C04. 착륙 허가

- 문법: `if` 표현식, 논리 연산자
- 연료가 30 이상이고 풍속이 20 이하일 때만 `true`를 반환합니다.
- 예시: `canLand(fuel = 40, wind = 15) == true`

### C05. 위험 등급

- 문법: `when`, 범위 `in`
- 위험도 `0..100`을 `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`로 분류합니다.
- 범위 밖의 값은 `INVALID`로 처리합니다.
- 경계: `0..24`, `25..49`, `50..74`, `75..100`

### C06. 행성 코드 해석

- 문법: `when`의 여러 조건 묶기
- 행성 코드 `M`, `V`, `E`를 이름으로 바꾸고, 대소문자는 구분하지 않습니다.
- 알 수 없는 코드는 `"UNKNOWN"`을 반환합니다.

## 3단계 — 반복과 제어 흐름

### C07. 통신 카운트다운

- 문법: `downTo`, `step`, `joinToString`
- `start`부터 0까지 2씩 감소하는 문자열을 만듭니다.
- 예시: `countdown(6) == "6, 4, 2, 0"`

### C08. 첫 번째 신호

- 문법: `for`, `break`, 인덱스
- 정수 목록에서 처음 등장하는 양수의 인덱스를 반환합니다.
- 양수가 없으면 `-1`을 반환합니다.

### C09. 배터리 충전 횟수

- 문법: `while`, 가변 상태
- 현재 배터리에서 한 번에 7씩 충전할 때 목표치 이상이 되기까지의 횟수를 구합니다.
- 이미 목표치 이상이면 `0`입니다.

## 4단계 — null 안전성

### C10. 선장의 별명

- 문법: 안전 호출 `?.`, 엘비스 연산자 `?:`
- 별명이 `null`이거나 공백뿐이면 `"ANONYMOUS"`를 반환합니다.
- 그 외에는 앞뒤 공백을 제거하고 대문자로 반환합니다.

### C11. 센서값 파싱

- 문법: `toIntOrNull`, nullable 타입
- 문자열을 정수로 변환하되 실패하면 `null`을 반환합니다.
- 변환된 값이 `0..100` 범위 밖이어도 `null`을 반환합니다.

### C12. 예비 좌표 선택

- 문법: nullable 값, 스마트 캐스트
- 주 좌표가 있으면 사용하고, 없으면 예비 좌표를 사용합니다.
- 둘 다 없으면 `"좌표 없음"`을 반환합니다.

## 5단계 — 컬렉션

### C13. 유효한 대원 ID

- 문법: `filter`, `distinct`, `sorted`
- 양수 ID만 남기고 중복을 제거한 뒤 오름차순으로 반환합니다.
- 예시: `[3, -1, 2, 3, 0] -> [2, 3]`

### C14. 자원 이름표

- 문법: `mapIndexed`
- 자원명을 `"1. WATER"`, `"2. FOOD"` 형식으로 변환합니다.
- 입력 문자열은 대문자로 바꿉니다.

### C15. 온도 보고서

- 문법: `minOrNull`, `maxOrNull`, `average`
- 온도 목록에서 최저, 최고, 평균을 담은 `TemperatureReport` 데이터 클래스를 반환합니다.
- 빈 목록의 처리 방법은 직접 정책을 정해 주석으로 설명합니다.

## 6단계 — Map과 그룹화

### C16. 자원 재고 합치기

- 문법: `MutableMap`, Map 순회
- 두 재고 Map을 합치며 같은 자원은 수량을 더합니다.
- 원본 Map은 변경하지 않습니다.

### C17. 대원 직군 분류

- 문법: `groupBy`
- `Crew(name, role)` 목록을 직군별 대원 이름 목록으로 변환합니다.
- 반환 타입: `Map<String, List<String>>`

### C18. 최고 점수 대원

- 문법: `maxByOrNull`, Map entry 구조 분해
- 이름과 점수가 담긴 Map에서 최고 점수의 이름을 반환합니다.
- 동점이면 이름이 사전순으로 빠른 대원을 선택합니다.

## 7단계 — 클래스와 객체

### C19. 탐사 로봇

- 문법: 클래스, 프로퍼티, 메서드, `private set`
- `Robot`은 이름과 초기 에너지를 받습니다.
- `move(cost)`는 에너지가 충분할 때만 차감하고 성공 여부를 반환합니다.
- 외부에서는 에너지를 직접 변경하지 못하게 합니다.

### C20. 임무 기록

- 문법: `data class`, `copy`, 불변 객체
- `MissionLog(id, status, memo)`를 선언합니다.
- 원본을 바꾸지 않고 상태만 `DONE`으로 변경한 복사본을 만드는 함수를 작성합니다.

### C21. 승무원 등급

- 문법: `enum class`, 프로퍼티와 메서드
- `ROOKIE`, `EXPERT`, `COMMANDER`가 서로 다른 권한 수준을 갖도록 만듭니다.
- 숫자 권한을 받아 사용할 수 있는 등급인지 판별합니다.

## 8단계 — 상속과 인터페이스

### C22. 신호 송신 장치

- 문법: `interface`, 구현 클래스
- `Transmitter` 인터페이스에 `send(message): String`을 정의합니다.
- `RadioTransmitter`와 `LaserTransmitter`가 서로 다른 접두사를 붙이도록 구현합니다.

### C23. 탐사 대상

- 문법: `sealed class`, exhaustive `when`
- `Planet`, `Asteroid`, `Unknown`을 표현하는 sealed 계층을 만듭니다.
- 대상별 착륙 안내 문구를 반환하되 `else`를 사용하지 않습니다.

### C24. 측정 가능한 객체

- 문법: 추상 클래스, `override`
- 추상 클래스 `SpaceObject`에 `mass()`를 정의하고 두 하위 클래스에서 계산식을 구현합니다.

## 9단계 — 고차 함수와 확장 함수

### C25. 측정값 변환기

- 문법: 함수를 파라미터로 받기, 함수 타입 `(Int) -> Int`
- 정수 목록과 변환 함수를 받아 모든 원소에 적용합니다.
- 직접 `map`을 사용하는 버전과 반복문 버전을 각각 작성합니다.

### C26. 안전한 재시도

- 문법: 고차 함수, 반복, 예외 처리
- 작업 `action: () -> Boolean`을 최대 `maxAttempts`번 실행합니다.
- 성공하면 실제 시도 횟수를, 모두 실패하면 `-1`을 반환합니다.

### C27. 호출 부호 확장 함수

- 문법: 확장 함수
- `String.toCallSign()`을 작성해 공백을 `-`로 바꾸고 대문자로 변환합니다.
- 연속된 공백은 하이픈 하나로 처리합니다.

## 10단계 — 스코프 함수와 실전 조합

### C28. 설정 생성기

- 문법: `apply`
- `MissionConfig` 객체를 생성한 뒤 여러 프로퍼티를 `apply` 블록에서 설정합니다.
- 생성된 객체를 그대로 반환합니다.

### C29. 안전한 사용자 표시

- 문법: `let`, `run`, nullable 체이닝
- nullable `Crew`가 있으면 `"이름 (직군)"`을, 없으면 `"미배정"`을 반환합니다.
- 불필요한 `!!` 사용은 금지합니다.

### C30. 탐사 결과 파이프라인

- 문법: 컬렉션 체이닝, nullable 변환, 구조 분해
- `"대원명:점수"` 문자열 목록을 파싱합니다.
- 잘못된 입력은 버리고, 60점 이상만 남기고, 점수 내림차순·이름 오름차순으로 정렬합니다.
- 최종 결과를 `"1위 이름(점수)"` 형식의 문자열 목록으로 반환합니다.
- 예시 입력: `["Neo:90", "bad", "Trinity:90", "Morpheus:55"]`
- 기대 결과: `["1위 Neo(90)", "2위 Trinity(90)"]`
