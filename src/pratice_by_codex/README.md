# Codex Kotlin 학습 트랙

Kotlin을 주 언어로 익히기 위한 실습 공간입니다. 기존 `src/practice_by_claude`와 분리하여 Codex가 만든 문제만 관리합니다.

## 트랙

- [기본 문법 문제 기획서](./기본문법/README.md): 기본·중급·고급·최고급 30문제
- [실전 문법 문제 기획서](./실전문법/README.md): API 설계·타입 시스템·위임·지연 처리·DSL 30문제
