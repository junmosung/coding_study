# Agent Kotlin 학습 트랙

Kotlin을 주 언어로 익히기 위한 실습 공간입니다. `pratice_by_codex`와 분리하여 Agent가 만든 문제만 관리합니다.

## 트랙

| 순서 | 트랙 | 목표 | 문제 |
|---:|---|---|---|
| 1 | [기본 문법](./기본문법/README.md) | `val`/`var` → 클래스 → Thread 기초 | A01~A36 |
| 2 | [심화 문법](./심화문법/README.md) | 표준 관용구 · 제네릭 심화 · DSL · JVM 동시성 | B01~B28 |

## 디렉터리 구조

```text
pratice_by_agent/
├── README.md
├── 기본문법/
│   ├── A_기본/     A01~A10
│   ├── B_중급/     A11~A20
│   ├── C_고급/     A21~A28
│   └── D_최고급/   A29~A36
└── 심화문법/
    ├── A_기본/     B01~B08
    ├── B_중급/     B09~B16
    ├── C_고급/     B17~B22
    └── D_최고급/   B23~B28
```

권장 순서: **기본문법 전체 완료 → 심화문법**.
